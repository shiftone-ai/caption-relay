# Caption Relay

UDトークまたはマイクの音声認識から届いた字幕を訂正し、観客へ配信するローカルの検証用アプリです。UDトークの公式製品・公式連携ではありません。

- **独立配信**: UDトークのZoom連携またはマイクから字幕を受け取り、Caption Relayの観客画面へ配信します。
- **UDトークへ反映（試験接続）**: 編集用の参加リンクから字幕を受け取り、訂正をUDトークへ返します。観客はUDトークの字幕画面を使います。

字幕は手動で訂正できます。APIキーを設定するとAI校正も使えます。AIは初期状態ではオフで、キーがない場合や通信に失敗した場合は原文を保持します。

## 使い始める

Mac向けのTauri開発版はPythonなどを同梱し、アプリを開くだけで起動します。導入・ビルドと確認済みの範囲は[Mac版](docs/macos.md)を参照してください。一般配布用の署名・公証は未実施です。

Web版は次の手順で起動します。

1. [準備と起動](docs/setup.md)に従い、必要なツールを導入してアプリを起動します。
2. ホーム <http://127.0.0.1:24681/> からルームに接続します。実機を使わずに試す場合は、独立配信の「準備」からテスト字幕を送れます。
3. 字幕の行を選んで訂正し、独立配信では「保存して公開」を押します。観客画面は操作画面のモニターアイコンから開けます。UDトークへ反映する場合は「保存してUDトークへ反映」を押します。

入力や配信先の設定、AI、辞書、終了方法は[利用者向けマニュアル](docs/manual.md)を参照してください。

## 利用上の制約

ローカルの単一プロセスで使用します。Web版は未認証、Mac版は起動ごとの認証で内蔵サーバーを保護します。LANへの公開は対象外です。字幕は再起動すると消えますが、ルームの接続履歴・設定と単語辞書は保存先に残ります。未保存の下書きは観客へ送られず、人が保存した文は後から届いた入力で上書きされません。

独立配信の受信・手動訂正・公開は実機で確認しています。UDトークへの手動訂正とGPT-5.4 MiniによるAI訂正、英訳更新、60分・120回の連続運転は合成音声を使った実接続で確認しました。マイク入力も合成音声で確認していますが、物理マイクと会場の音響、60分を超える運転、各AIの品質比較は未確認です。詳細は[入力接続](docs/udtalk-input.md)と[マイク入力](docs/microphone-input.md)を参照してください。
