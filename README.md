# Caption Relay

認識結果のテキストを受け取り、人が字幕を修正して観客画面へ配信するローカル PoC です。操作画面と観客画面は React・TypeScript・XState、バックエンドは FastAPI・Pydantic v2 を使用します。

入力文、または入力に対応するAI修正結果を字幕として採用します。Gemini・Claude・Codexの選択と振り分け、AI修正結果を受け取るAPIを用意しています。AIへの接続自体はまだありません。UDトーク実機との接続、AIによる整形、認証、永続化は未実装です。単一プロセスで使用し、外部へ公開しないでください。再起動すると字幕は消えます。

## 起動

Node.js、Python 3.12、npm、uv が必要です。推奨バージョンと環境変数は[開発手順](docs/development.md)を参照してください。プロジェクトのルートから実行します。

```bash
bash scripts/setup.sh
bash scripts/dev.sh
```

| 画面 | URL |
|---|---|
| 操作画面 | <http://127.0.0.1:24681/> |
| 観客画面 | <http://127.0.0.1:24681/view/demo> |

`setup.sh` は依存関係を導入し、画面をビルドします。終了時はサーバーを Ctrl+C で止めます。フロントエンドの変更を即時確認する手順は[開発手順](docs/development.md)、Codex Cloud と SSH 接続は[リモート開発](docs/remote-development.md)に記載しています。

## 試す

1. 操作画面の「準備」を開き、「テスト字幕を送る」を押します。自動公開中は観客画面にも表示されます。
2. 観客画面に字幕が表示されることを確認します。
3. 操作画面の表示文をクリックして訂正欄を開き、修正して「保存して公開」を押します。Ctrl / Command + Enter でも保存できます。下書きを残したまま「最新へ」と「訂正位置へ」で履歴を往復できます。
4. 「字幕を隠す」で観客への表示を止め、「字幕を表示」で新しい発話から再開します。
5. 「表示設定」で背景・フォント・文字サイズなどを変更し、「表示設定を反映」を押します。観客画面を別ディスプレイへ移し、全画面ボタンで表示します。
6. 「新着の公開」で「自動公開」と「確認して公開」を切り替えます。どちらの方法でも、人の修正には明示的な保存が必要です。
7. ロボットのアイコンから「AI設定」を開き、AIの指定・費用優先・実測の速度優先を選んで保存します。現段階では振り分け先を記録するだけで、AIへ送信しません。比較条件と料金は[AIの選択と振り分け](docs/ai-routing.md)を参照してください。

未保存の下書きは観客へ送られません。人が保存した文は後着の入力で上書きしません。編集競合、非表示期間、入力 API の詳細は[現行 PoC の仕様](docs/current-behavior.md)を参照してください。
