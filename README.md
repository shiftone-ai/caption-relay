# Caption Relay

UDトークまたはマイク認識の字幕を、AIと手動で訂正して観客へ配信するローカル PoC です。会場での字幕編集を試すための検証用アプリで、UDトークの公式製品・公式連携ではありません。

「独立配信」と「UDトークへ反映」の2つの接続方法を選べます。操作画面と観客画面は React・TypeScript・XState、バックエンドは FastAPI・Pydantic v2 を使用します。

独立配信では、UDトークのZoom連携から字幕を受信し、このアプリの観客画面へ配信します。UDトークへ反映する試験接続では、編集を許可した参加リンクを使って訂正を返し、純正の字幕表示・配信を使います。設定と検証範囲は[入力接続](docs/udtalk-input.md)を参照してください。

UDトークがない場合は、独立配信の入力元を「マイク」にし、OpenAIまたは接続先MacのApple認識を選べます。準備と開始・停止は[マイク入力](docs/microphone-input.md)を参照してください。両方とも合成音声で実認識を確認しています。物理マイクと会場での認識は未確認です。

AIは初期値オフです。サーバーにGemini・Claude・OpenAIのAPIキーを設定すると、次の確定字幕から校正を実行します。APIキー未設定時と失敗時は原文を保持します。認証と字幕の永続化はなく、ローカルの単一プロセスで使用します。再起動すると字幕と画面の設定は消えます。単語辞書は保存先に残ります。

## 起動

画面を見ながら操作する手順は[利用者向けマニュアル](docs/manual.md)を参照してください。

Node.js、Python 3.12、npm、uv が必要です。推奨バージョンと環境変数は[開発手順](docs/development.md)を参照してください。プロジェクトのルートから実行します。

```bash
bash scripts/setup.sh
bash scripts/dev.sh
```

| 画面 | URL |
|---|---|
| 操作画面 | <http://127.0.0.1:24681/> |
| 観客画面 | <http://127.0.0.1:24681/view/demo> |

`setup.sh` は依存関係を導入し、画面をビルドします。終了時はサーバーを Ctrl+C で止めます。フロントエンドの変更を即時確認する手順は[開発手順](docs/development.md)、Codex Cloud と SSH 接続は[リモート開発](docs/remote-development.md)に記載しています。

## 試す

1. 接続アイコンから「字幕入力の接続設定」を開き、「独立配信」の送信先をUDトークのZoom連携に設定します。実機を使わない画面確認は「準備」の「テスト字幕を送る」で行えます。
2. 表示文をクリックして訂正欄を開き、修正して「保存して公開」を押します。未保存の下書きは観客へ出ません。Ctrl / Command + Enterでも保存できます。
3. 「新着の公開」で自動公開・確認して公開を選びます。「字幕を隠す」は表示を止め、「字幕を表示」は新しい発話から再開します。
4. 「表示設定」を反映し、観客画面を別ディスプレイへ移して全画面表示します。純正へ返す場合は接続設定を「UDトークへ反映（試験接続）」に変更し、有効な編集用の参加リンクを適用します。訂正の表示はUDトーク側で確認します。
5. AIを使う場合は[開発手順](docs/development.md#環境変数)に従ってキーを設定し、再起動します。ロボットアイコンの「AI設定」で選び方を保存します。比較条件と料金は[AIの選択と振り分け](docs/ai-routing.md)を参照してください。

未保存の下書きは観客へ送られません。人が保存した文は後着の入力で上書きしません。編集競合、非表示期間、入力 API の詳細は[現行 PoC の仕様](docs/current-behavior.md)を参照してください。

2026-10-07の実機試験では独立配信の受信・手動訂正・公開を確認しました。2026-10-10には実APIと背景ブラウザで、訂正の公開、後着入力からの保護、話者表示、設定保存を確認しています。

編集参加からUDトークの純正画面への手動訂正とGPT-5.4 Miniの自動訂正は、合成音声を使った実接続で確認しました。UDトーク経由の英訳更新と60分・120回の連続運転も、合成音声で確認しました。[翻訳・連続運転の記録](docs/udtalk-input.md#翻訳と連続運転の確認)を参照してください。各AIの品質比較、会場条件、60分を超える運転は未確認です。実接続の範囲は[入力接続](docs/udtalk-input.md#復旧後の実接続確認)と[AIの選択と振り分け](docs/ai-routing.md#実接続での確認)を参照してください。公開前の点検範囲と履歴の確認事項は[公開前の点検](docs/publication-check.md)に記載しています。
