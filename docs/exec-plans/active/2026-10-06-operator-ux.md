# 操作画面のUX改善

## Goal

過去2回のUXレビューとアイコン整列の指摘を改善し、実操作で検証したPRをマージする。最後はローカルmainをorigin/mainと同期し、Gitの作業ツリーをクリーンにする。

## Context

現在はcodex/docs-navigation。既存の字幕編集、表示設定、AI選択、Root配下のPassive ViewとMediatorへの移行が未コミット。レビューの証拠は.impeccable/critique/にある。認証・永続化・外部AI接続は現行PoCの対象外。

## Scope and Non-Goals

操作画面、観客画面と同じ条件での表示プレビュー、関連するMediator・Presenter・描画Adapter・テスト・現行仕様の更新。外部AI接続、本番公開、字幕の要約・翻訳は含まない。

## Constraints From Decisions

- 原文と保存済み表示文を並べ、十分な履歴を表示する。長文を省略しない。
- 受信・AI結果は公開設定に従い、人の下書きは明示保存まで公開しない。
- 状態はアイコン中心。名前と説明をキーボード・支援技術にも渡す。
- 全コンポーネントにRoot配下のScopeを設け、操作をChain経由でMediatorへ渡す。
- 8pxの余白と部品寸法を維持する。
- ユーザーが判断・並列作業・PR・マージを許可している。既存の白地の操作UIを改善する。

## Remaining Work

- 現在の変更をレビュー・検証し、土台のPRをマージする。
- 独立worktreeで字幕監視と訂正、プレビュー、設定導線を分担する。
- 長文訂正中に直近の複数発話を見せ、新着数・境界・訂正位置への往復を設ける。
- 閉じた行は保存済み文を示し、未保存の版を公開済みと誤読させない。
- 設定を開閉したときのフォーカスと、字幕本文・列・状態の読み取りを改善する。
- 文字サイズ・行間・余白・件数・比率を反映する縮尺付きプレビューにする。
- 新着公開と人の保存を区別し、テスト送信を準備用の操作へ移す。
- リサイズ後の追従、モバイル設定中の監視、AI指定先の役割、設定の一覧性を改善する。
- 未保存の離脱、保存成功、エラー・競合・再開状態の既存指摘も確認する。
- 統合後に実ブラウザで操作とAPI通信を確認し、必須検証と独立レビューを通す。
- 文書を更新し、この計画を削除して改善PRを作成する。CIとレビューを解決してマージする。
- 作業用worktreeを保存して片付け、ローカルmainを同期してクリーンな状態を確認する。

## Now And Next

土台の差分をレビューする。並行して、訂正欄を横に固定し新着を常時監視できる画像案を作る。土台をマージしたらファイル所有範囲を分けて作業する。

## Blockers And Human Tasks

なし。実会場・物理ディスプレイ・IME・VoiceOverの実機検証はこの環境で実施できず、完了報告で区別する。

## Verification

- 20件以上の混在長文で訂正中も新着の前後を確認でき、下書きが公開されない。
- 未保存行の文と公開状態、非表示から再開した状態を誤読しない。
- 設定開閉と本文編集をキーボードで行える。保存失敗・競合で下書きが残る。
- 全表示項目がプレビューと観客画面で対応する。
- デスクトップ・390px幅・200%相当の幅で横方向のはみ出しや操作の欠落がない。
- bash scripts/check.sh、GitHub CI、独立コード/画面レビューが通る。
- 改善PRがマージ済みで、ローカルmainのHEADがorigin/mainと一致しgit status --shortが空。
