# UDトークの実機音声認識の確認

## Goal

UDトークの実機音声認識を入力Adapterで取り込み、操作画面と観客SSEまで証拠付きで確認し、PRをレビュー可能にする。

## Context

- 基点はmainの `5b0b69ba92eed387caff856aebea24c14d4f209d`。作業ブランチは `codex/udtalk-input`。
- 実験用Web入力Adapterと変換・再送・取消・手修正保護の回帰テストがある。設定・制約・実ブラウザ画像は `docs/udtalk-input.md` を参照する。
- 実機はApple SiliconのMac上のiOS版UDトークver.344。Mac／Windows用編集アプリとは異なる。文字入力から操作画面・観客SSEへの実接続は確認済み。音声の認識文はまだ得られていない。
- Web取得は公式ビューアの配信コードを観察したHTTP経路で、保証された公開APIではない。閲覧リンクをリポジトリ・PR・証拠画像に含めない。
- 試験の認識・Web公開・ローカルサーバーは停止済み。再開時は実機でWeb公開を再開してから接続する。

## Scope and Non-Goals

- 実機の音声認識、入力変換、操作画面・観客SSE、必要な修正・検証、文書、PR。
- 外部AI、認証・永続化の新設、元checkout、会場性能評価は範囲外。

## Constraints From Decisions

- 断片番号を改版番号として扱わない。実データと模擬応答の検証を区別する。
- 手修正を保護し、未保存の下書きと入力の管理情報を公開しない。
- 既存の画面構成と責務を維持し、ブラウザを背景で操作する。
- システムのマイク入力先は利用者の回答なしに変更しない。

## Remaining Work

1. マイク設定の回答を受け、UDトークで音声認識文を得る。
2. 認識文の途中／確定と断片の実データを照合し、操作画面・観客SSEへの到達を記録する。
3. 必要な修正とチェックを完了し、文書・PRの未確認事項を更新する。
4. 試験用の接続を終了し、この計画を削除して結果をPRへ記載する。

## Now And Next

利用者のマイク設定の回答を確認する。MacBookのふたを閉じている場合、Studio Display Microphoneへの切り替え許可が必要。回答後は試験専用トークで認識を開始し、短い日本語を発話してもらう。

## Blockers And Human Tasks

UDトークの認識は開始できたが、MacBook Pro Microphoneから認識文を得られていない。ふたの開閉とStudio Display Microphoneへの変更許可を質問中。実機の発話確認は未完了として扱う。

## Verification

- 実機の認識文が操作画面・観客画面へ届き、実APIとSSEの証拠がある。
- 途中／確定、断片、改版、再送の意味が実データと一致する。
- 後着入力が手修正を上書きせず、下書きと管理情報を公開しない。
- `bash scripts/check.sh` が成功する。
- PRに端末・経路・実接続の成否と未確認事項を記載する。
