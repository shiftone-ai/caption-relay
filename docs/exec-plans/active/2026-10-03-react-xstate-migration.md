# Goal

操作画面と観客画面を TypeScript、React、XState、shadcn/ui へ移し、Root 配下の Passive View とイベント伝播を使用する。

# Context

- 現行 API は FastAPI の単一プロセス・インメモリ実装。認証と実 Gemini 接続はない。
- TypeScript、React、XState、shadcn/ui、Pydantic v2 の移行と API 型生成は実装済み。型検査、型の一致確認、ビルド、フロント 13 件・バック 17 件のテストが通る。
- 実ブラウザでテスト入力、下書き保持、反映、観客配信、表示切り替え、再読み込みを操作した。競合検証の途中でブラウザ接続が失われた。
- 作業フォルダに `.git` がなく、ブランチと変更差分を Git で取得できない。

# Scope and Non-Goals

フロントエンドの移行、ビルド配信、FastAPI/Pydantic v2 の型付け、OpenAPI の TypeScript 型生成、責務の文書化、対象操作の検証。認証、永続化、整形機能は追加しない。

# Constraints From Decisions

- ユーザー操作をコンポーネントの親へ伝播させ、Root の XState actor へ届ける。
- View は描画パラメータと入力イベントのみを扱う。Presenter は状態を描画パラメータへ変換する。
- 新旧実装を並行維持しない。既存 API のパスと観客画面の URL を維持する。
- 開発用ポートはプロジェクト専用とし、既存のサーバーを停止しない。
