# 準備と起動

Caption Relayはローカルで動く検証用アプリです。手動訂正と独立配信にはAPIキーは不要です。AI校正やマイク入力を使う場合は、それぞれの準備を行ってください。

## 必要なツール

Node.js、npm、Python 3.12、uv が必要です。Node.jsは22.23.4以上の22系、24.22.1以上の24系、または26.12.1以上を使ってください。推奨バージョンは[開発手順](development.md#前提)に記載しています。

セットアップスクリプトはmacOSとLinux向けです。Appleの音声認識を使う場合は、macOS 26 SDKでの補助プログラムのビルドと日本語モデルの準備も必要です。Windowsでの起動は未確認です。

## リポジトリの取得

Gitを使う場合は、ターミナルで次のコマンドを実行します。GitHub Releaseからソースコードをダウンロードして展開する方法でも使えます。

```bash
git clone https://github.com/shiftone-ai/caption-relay.git
cd caption-relay
```

## 起動

ターミナルでこのリポジトリのフォルダに移動し、次のコマンドを実行します。初回と依存関係を更新した後は、セットアップが必要です。

```bash
bash scripts/setup.sh
bash scripts/dev.sh
```

ブラウザで <http://127.0.0.1:24681/> を開きます。終了するときは、サーバーを起動したターミナルで Ctrl+C を押してください。

字幕はサーバーの再起動で消えます。ルーム設定と単語辞書は残ります。外部へ公開する認証機能はないため、この起動方法のままローカルで使ってください。

## AI校正のAPIキー

Gemini、Claude、OpenAIのいずれかのAPIキーを、サーバーを起動する前に設定します。AIを使わない場合は不要です。次はGeminiの例です。

```bash
read -r -s GEMINI_API_KEY
export GEMINI_API_KEY
bash scripts/dev.sh
```

入力待ちになったらキーを貼り付け、Enterを押します。Claudeは `ANTHROPIC_API_KEY`、OpenAIは `OPENAI_API_KEY` を同じ方法で設定してください。起動スクリプトは `.env` を自動で読み込みません。キーを後から設定する場合は、サーバーを停止してから設定し、再起動してください。

起動後に操作画面の「AI設定」でモデルを選んで保存すると、次の確定字幕から校正します。AIの結果は公開前に確認してください。

## マイク入力の準備

OpenAIの音声認識には専用キーと試験費用の設定、Appleの音声認識には対応するMacと日本語モデルが必要です。詳しくは[マイク入力](microphone-input.md)を参照してください。

OpenAIのマイク入力には累積20分・見積もり90円の送信上限があります。ローカルPoCの試験用の制限であり、長時間の会場運用を想定した設定ではありません。
