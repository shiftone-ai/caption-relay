# 画面全体の表示・操作確認

画面を変更したときは、ツールバーなど一部分だけの確認で完了としない。ホーム、操作画面の各領域と設定、確認ダイアログ、観客画面を次の表で確認する。

## 確認範囲

| 場所 | 確認する状態・操作 |
|---|---|
| ホーム | 一覧、登録・変更、独立配信・編集参加、長い名前と背景、入力エラー、読込失敗、取消とフォーカス復帰 |
| ツールバー | 公開方法、表示切り替え、準備・説明の開閉、設定と観客画面への移動 |
| 入力と観客表示の監視 | 空、長文、発話者、途中字幕、表示・非表示、領域内のスクロール |
| 字幕一覧 | 空、長文、多数の行、状態説明、新着、履歴フッター、「最新へ」「編集中の字幕へ」 |
| 訂正欄 | 原文、下書き、変更前の文、履歴選択、保存、再公開、空欄、競合、保存失敗・再確認、閉じた後の復帰 |
| 接続設定 | 独立配信、マイク、編集参加、各説明、入力エラー、適用操作 |
| AI設定 | オフ、モデル選択、背景、料金表とリンク、説明、入力エラー、保存、処理中・失敗の字幕 |
| 単語辞書 | 空、追加・削除、有効切り替え、各入力欄、入力エラー、保存、保存済みへ戻す |
| 表示設定 | スクロール・直近の字幕、件数、全ての詳細欄、配色・色入力、説明、プレビュー、反映 |
| 確認ダイアログ | リセット、未保存での離脱、長い日本語・空白のない名前、取消・確定・Escape |
| 観客画面 | 空、非表示、長文、多数の発言、過去を読む・最新へ戻る、全画面・解除・失敗、操作と字幕の重なり |

通常状態だけでなく、展開した内容、長文、エラー文が増えた状態でも確認する。画面だけが開くことと、操作が完了することを区別する。

## 寸法と操作の基準

- 320px・390px幅、横向きの低い画面、720px・767px・768px付近、広い画面を確認する。文字を拡大した場合も操作が欠けないか確かめる。
- 余白と部品寸法は4px単位を使う。タップする説明・開閉・リンク・入力・有効切り替えも確認し、主要操作は44px以上の領域を確保する。文字サイズと細い輪郭は余白の単位から分ける。
- 横のはみ出し、重なり、切れたフォーカス輪郭、スクロールできない内容、届かない保存操作を残さない。本文が長いときは途中で切らず、折り返しとスクロールで読めるようにする。
- 狭い画面で訂正・設定を開いたときと、高さの低い画面では、ページを縦にスクロールして入力と保存へ移動できることを確かめる。画面幅だけでタッチ操作の寸法を決めない。
- 実APIを使って保存・適用・移動を完了し、結果を確認する。ドラッグなど独自の操作は、開始だけでなく終了・取消と、周囲のスクロールも確認する。

## ブラウザ回帰テスト

初回はプロジェクトのセットアップ後にChromiumを導入する。

```bash
npm --prefix frontend exec -- playwright install chromium
npm --prefix frontend run test:browser
```

[`playwright.config.ts`](../frontend/playwright.config.ts) は、320×720px・390×844px・844×390pxで[`mobile-layout.pw.ts`](../frontend/browser-tests/mobile-layout.pw.ts)を実行する。登録と長い名前の確認、長い競合後の再保存、全設定内の主要操作と辞書保存、観客のスクロール・全画面・プレビューとの寸法一致を確認する。

[`browser_test_server.py`](../scripts/browser_test_server.py) は127.0.0.1:24741で隔離した実FastAPIを起動する。字幕・ルーム・辞書は試験用で、通常の保存先は読み書きしない。外部AI・UDトーク・マイク認識は接続しない。他の開発サーバーを再利用しない。終了後はサーバーと一時ファイルを片付ける。

テスト前にフロントエンドをビルドする。実行結果と失敗時の画像・トレースは `frontend/test-results/browser/` に出力し、リポジトリには含めない。全体検査の `bash scripts/check.sh` も実行する。GitHub ActionsではChromiumと日本語フォントを導入し、同じブラウザ回帰テストを実行する。

## 目視と確認記録

自動テストは目視の代わりにはならない。全ての領域の画像と実操作を確認し、別の確認者による画面監査を行う。確認表には画面・状態、画面幅と高さ、操作結果、証拠、未確認事項を残す。検出器の指摘なしだけで完了にしない。

ブラウザの画面幅変更、合成タッチ、ブラウザ標準の拡大、CSSによる拡大、スマートフォン実機を区別する。外部サービスの試験応答は実接続の証拠にしない。未確認の実機・キーボード・入力・接続は確認済みと書かない。
