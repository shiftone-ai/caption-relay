# UDトークの字幕出力を参照した表示設定

調査日：2026-10-05。UDトーク公式のMac / Windows操作ガイドを参照した。実機は操作していない。

[字幕・カメラ出力の公式ガイド](https://service.udtalk.jp/apps/udtalk-pc/captions/index.html)では、別ウィンドウへの字幕表示と、出力用の表示設定を提供している。編集結果も出力側へ反映され、設定はトークごとに保存される。

| 公式ガイドで確認した項目 | Caption Relayの今回の対応 |
|---|---|
| 別ウィンドウに字幕を表示 | 観客画面を別ウィンドウで開く |
| システム標準・利用可能なフォント | 表示端末のゴシック・明朝・等幅 |
| 文字サイズ24〜96px | 同じ範囲を8px刻みで選択 |
| 太さ・行間・文字色・背景色 | 表示設定で調整 |
| 16:9とウィンドウ比率、表示領域の余白 | 16:9／画面に合わせる、共通の余白 |
| 認識・編集の途中経過を表示するか選択 | 確定した入力と明示保存だけを公開 |
| 読み仮名・翻訳・縁取り・ハイライト | 今回は提供しない |
| 仮想カメラへの出力 | 今回は提供しない |

公式の[設定ガイド](https://service.udtalk.jp/apps/udtalk-pc/settings/index.html)は、編集用の画面設定と字幕出力用の設定を分けている。Caption Relayでも、操作一覧の密度と観客画面の文字サイズを別に扱う。

公式の[Web字幕の全画面表示案内](https://udtalk.jp/post-4633/)は、投影時に管理用の表示を減らし、背景や文字サイズを調整できることを案内している。Caption Relayの観客画面も字幕を主体とし、全画面時には表示切り替えボタンを隠す。

UDトークと同じ機能をすべて再現したものではない。Caption Relayの設定は現行PoCのサーバーメモリに保存し、再起動で消える。実装の詳細は[現行PoCの仕様](current-behavior.md#別画面の表示設定)を参照する。
